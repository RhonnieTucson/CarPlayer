# CarPlayer (Kotlin + Jetpack Compose + Media3)
1. Abre esta carpeta en Android Studio (Koala o superior) y deja que sincronice Gradle.
2. Ejecuta en un dispositivo o emulador (Android 8.0+). Al iniciar concede permiso de audio.
3. APK de prueba: Build > Build Bundle(s)/APK(s) > Build APK(s).
Versión completa: biblioteca (6 pestañas reordenables, listas, cuadrícula/lista/detalle, A-Z), reproductor dividido, ecualizador del sistema, 21 temas, temporizador, velocidad, cola, modo bloqueo, carpetas excluidas.
